# Calamity Mod

### The definitive Terraria total conversion experience

The Calamity Mod is the most ambitious Terraria mod ever created, adding over 1900 items, 24 bosses, and completely new game progression far beyond the vanilla endgame. A full second game built inside Terraria.

<br>

---

## Features

| | |
|:---|:---|
| **24+ Bosses** | An entire extended progression of powerful new bosses beyond Moon Lord |
| **1900+ Items** | Weapons, armor, accessories, and tools for every playstyle imaginable |
| **New Biomes** | Explore the Sulphurous Sea, Astral Infection, Calamity biomes, and more |
| **Revengeance Mode** | Optional hardcore difficulty with unique boss behaviors and mechanics |
